# Visual HSL

Place colours in a 3D HSL cylinder and fine-tune them with on-model controls.

- Drag to rotate, scroll to zoom.
- Click a point or a square to select it. Drag the ruler on the left (lightness), the
  ring (hue) or the ticks on the radius line (saturation) to move it.
- Type a hex value in the panel, add colours with `+` (up to 12), remove with `×` or
  `Delete`, deselect with `Escape`. Colours are saved in the browser.

```
npm install
npm run dev     # start the app
npm test        # colour maths unit tests
npm run build   # type-check and build
```
